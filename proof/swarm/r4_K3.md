### 2. Requirements (exact, from the master inequality)

Let t = number of T-heavy arcs in pattern (A), and z = number of zero T-arcs forced.

Zero-forcing count: at a V1 tail v, #(zero T-out-arcs) = sum over x>=2 T-out-arcs at v of (x-1). So z = sum over T-heavy arcs of (x-1).

Pattern (A), three arcs with x = 2 (t of them T-type, 3-t of them M-type):
- z = t (each T-heavy needs one zero at its tail; zeros are distinct arcs, one per T-heavy arc).
- 2 ex = 2[ 12(3-t) + 0*t + 11 z ] = 2[12(3-t) + 11t] = 72 - 2t.
- eta_T = t, eta_M = 3 - t.
- **R_A(t) = 520 + (72 - 2t) - 147 t - 138 (3 - t) = 178 - 11 t.**
  - t = 0 (all M): R = 178.
  - t = 1: R = 167.
  - t = 2: R = 156.
  - t = 3 (all T): R = 145. (Matches the expected 145.)

Pattern (B), one arc with x = 3:
- T-type: z = 2. 2 ex = 2[f_H(3) + 2 f_H(0)] = 2[12 + 22] = 68. eta_T = C(3,2) = 3. **R_B,T = 520 + 68 - 441 = 147.**
  - **Discrepancy with the expected value 123.** The expected 123 equals 520 + 2*(2*11) - 441, i.e. it drops f_H(3) = 12 from ex. The brief defines ex to include f_H(x) for all T-pairs, and f_H(3) = 12. So the requirement is 147. This is a correction, not a new fact.
- M-type: z = 0. 2 ex = 2*37 = 74. eta_M = 3. **R_B,M = 520 + 74 - 414 = 180.**

### 3. Tail contributions through one heavy pair (all other pairs have x in {0,1})

Setup: P = (p -> q) T-heavy (p,q in V1), or P = (c -> r) M-heavy (c in V0, r in V1). For a third vertex w, X = sum of the three pair x-values, a = #V1 vertices in the triple, t = X - a - sigma. Only t >= 1 contributes, with eps(14) = 2, eps(15) = 8, eps(16) = 20.

**3a. T-heavy P = (p -> q), x = 2.** Cyclic triples through P: 12 (cyc = 26 - 14). Each cyclic triple is p->q->w->p (w is the third vertex, with q->w and w->p).
- w in V0: q->w has head in V0, so x = 0. X = 2 + x(w,p), a = 2, sigma = 0. t = x(w,p) <= 1. Contribution <= 2.
- w in V1: X = 2 + x(q,w) + x(w,p), a = 3, sigma = 0. t = x(q,w) + x(w,p) - 1 <= 1. Contribution <= 2.
- So every cyclic triple through P contributes at most 2.

Transitive triples through P (38 of them). Positions of w:
- w source (w -> p, w -> q). w in V0: a = 2, sigma = 1, X = 2 + x(w,p) + x(w,q), t = x(w,p) + x(w,q) - 1 <= 1, contribution 2 only when both M-arcs have x = 1. Such w lie in D(P) cap V0. Count <= min(gamma_p, gamma_q) (non-heavy M-mass into p and into q). w in V1: a = 3, t = sum - 2 <= 0.
- w between (p -> w -> q). w in V0: the arc p->w has head in V0, so x = 0. X = 2 + x(w,q), t = x(w,q) - 1 <= 0. w in V1: t = X - 4 <= 0.
- w sink (p -> q, p -> w, q -> w). w in V0: X = 2, t = -1. w in V1: t <= 0.
- Conclusion: transitive triples contribute only as "source in V0 with both M-arcs at x = 1", each contributing 2.

Summary for T-heavy x = 2: the total contribution of single-heavy triples through P is at most 2*(12) + 2*min(gamma_p, gamma_q), where gamma is the non-heavy M-mass into the endpoint from V0.

**3b. M-heavy P = (c -> r), x = 2, c in V0, r in V1.** Cyclic triples through P: 11 (cyc = 25 - 14 = 11 for x = 2; formula 13 - x). The cyclic orientation is c->r->w->c.
- w in V0: r->w and w->c both have heads in V0, so x = 0. X = 2, a = 1, sigma = 0, t = 1. Contribution exactly eps(14) = 2 per cyclic V0-triple.
- w in V1: X = 2 + x(r,w), a = 2, t = x(r,w) <= 1. Contribution <= 2.
- So each cyclic triple through P contributes at most 2.

Transitive triples through P (39 of them):

### 4. Pattern (A): three pairs with x = 2

Two global masses (non-heavy, i.e. x in {0,1}): gamma^nh total = 13 - (M-heavy mass) = 13 - 2m, where m = number of M-heavy arcs; d^nh total = 13 - 2m (V0 out-mass). For a vertex v, gamma^nh_v is its non-heavy M-in-mass from V0. Nonheavy T-count bounds use gamma^nh.

Base bound (all triples through heavy pairs, with 3a-3b assignments, each triple assigned at most 2 per occurrence): sum = T-cyc contributions + M-cyc contributions + D-part (T-heavy, V0 source) + M-V0-trans (<= 2 gamma^nh_r) + M-V1-trans (<= 2 d^nh_c). Multi-triples (containing two or three heavy pairs) get an extra allowance of 8 each (20 for a triangle), since their eps can be larger (X up to 5 or 6).

Shape of the heavy pairs (sharing a vertex means lying in a common triple):
- disjoint: no multi triples.
- path: two multi triples. Star (all three share one vertex): three multi triples. Triangle: all three pairs inside one triple (one multi triple).
- A V0 vertex (tail of an M-arc) can only be shared with M-arcs, and a V1 vertex can be shared with anything. So a star centred at a V0 tail needs all three arcs to be M; a star at a V1 vertex can mix.

**4a. t = 3 (all T), R = 145.**
- Each T-heavy pair: cyclic 12 triples at 2 each = 24. Three pairs: 72.
- D-part: 2 min(gamma^nh_p, gamma^nh_q) per pair. Sum over pairs of 2min <= sum of gamma^nh over endpoints with multiplicity, capped by 2 times the total 13 when a vertex is in two pairs (path, triangle) and by the leaf rule for a star (2min(gamma_v, gamma_u) <= 2 gamma_u, leaves distinct) giving 26 in each case. Disjoint: <= 13.
- Multi allowances: disjoint 0; path 2 x 8 = 16; star 3 x 8 = 24; triangle 20.
- Totals: disjoint <= 72 + 13 = 85; path <= 72 + 26 + 16 = 114; star <= 72 + 26 + 24 = 122; triangle <= 72 + 26 + 20 = 118.
- **All below 145. DEAD for every shape.** (The cyclic bound 12 x 2 per pair is exact for the count; eps 2 is the per-triple maximum for cyclic triples through a T-heavy x = 2 arc, from 3a.)

**4b. t = 0 (all M), R = 178.**
- Each M-heavy pair: cyclic 11 triples at 2 each = 22. Three pairs: 66.
- M-V0-trans: <= 2 gamma^nh_{r_P} per pair; M-V1-trans: <= 2 d^nh_{c_P} per pair. Combined over the three pairs: sum_P [2 gamma^nh_{r_P} + 2 d^nh_{c_P}] <= 2 (a + b) x 7, where a = max number of pairs with one head and b = max number with one tail, a + b <= 4 for three distinct pairs. So <= 56. (Head mass total and tail mass total are both 13 - 6 = 7.)
- Multi allowances: star at a V1 head (three M-arcs into r): 3 x 8 = 24; star at a V0 tail: 24; path: 16.
- Totals: <= 66 + 56 + 24 = 146.
- **146 < 178. DEAD.**

**4c. t = 1 (one T, two M), R = 167.**
- Cyclic: T pair 12 x 2 = 24; M pairs 2 x 22 = 44. Base 68.
- Non-heavy mass masses: gamma^nh and d^nh each total 13 - 4 = 9.
- Weighted mass part: a vertex's gamma-weight is [in T pair] + 2 [head of M pairs]; its d-weight (tails) is 2 per M pair with that tail. Maximum combined over configurations: if both M heads equal v and v is a T endpoint, the gamma part is at most 5 x 9 = 45, with the M tails distinct so the d part is at most 2 x 9 = 18: total 63. If the M tails are equal, the d part is at most 4 x 9 = 36 and the gamma part at most 3 x 9 = 27: total 63. Mixed: at most 45. So the combined mass part is at most 63.
- Base total <= 68 + 63 = 131.
- Multi allowances: at most three multi triples (star at a V1 vertex, 3 x 8 = 24) or one triangle triple (20). Triangle with two M-arcs from one V0 vertex c and the T-arc: {c, r1, p}, eps <= 20.
- Totals: <= 131 + 24 = 155 (or 151 for the triangle). **Below 167. DEAD.**

**4d. t = 2 (two T, one M), R = 156.**
- Cyclic: two T pairs 2 x 12 x 2 = 48; M pair 22. Base cyclic 70.
- Mass part: gamma-weight max 4 (a vertex in both T pairs and the head of the M pair), total 11, so 44 at most; d part 2 x 11 = 22. Base mass part at most 66. Base total <= 70 + 66 = 136.
- Shapes: since T pairs lie in V1 and the M pair has a V0 endpoint, the M pair can share a vertex only through its head r. So the number of pairs of heavy pairs that share a vertex k is 0, 1, or 3 (k = 2 forces all three through r, which is k = 3).
  - k = 0 (disjoint): base 136 < 156. DEAD.
  - k = 1: base 136 + 8 - (assigned value of the one shared triple, at most 2 per occurrence) <= 144 < 156. DEAD.
  - k = 3 (star at V1 vertex r, with M-arc c -> r and T-arcs {r, p1}, {r, p2}): multi triples {c, r, p1}, {c, r, p2}, {r, p1, p2}, each with eps <= 8 (checked: X <= 5, sigma and a bound t <= 2). Each such triple has base assignment at most 4 (it is counted in at most two cyclic lists and no mass list), so subtract at most 12. Totals <= 136 - 12 + 24 = 148 < 156. **DEAD.**
- So for t = 2, every shape is dead. The margin in the star case is 8.

**4e. Summary of pattern (A).** All four values of t are DEAD: all-M 146 < 178, one T 155 < 167 (triangle 151), two T <= 148 < 156 (star), all-T <= 122 < 145.

### 5. Pattern (B): one pair with x = 3 (no other x >= 2)

- Transitive V1 (source, between, sink) with t = 1: eps 2 each. Each needs a non-heavy x = 1 arc incident to p or q. Crude count bound: 2 x [(T-in-mass of p) + (non-heavy T-out-mass of p) + (non-heavy T-out-mass of q) + (T-in-mass of q)] <= 2 x (13 + 22 + 22 + 10) = 134.
