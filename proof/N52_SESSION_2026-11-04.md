## §1. Exact identities for every balanced tournament on 52 vertices (PROVED)

**Setting B.** T is any tournament on 52 vertices with every in-degree in {25, 26}. No F1, no Case A. V_0 = {d- = 25},
V_1 = {d- = 26}; since sum d- = C(52,2) = 1326 = 52*25 + 26, |V_1| = 26 = |V_0|. e(v) = [v in V_1]. For a vertex y,
f(y) := |N+(y) ∩ V_1|. For a triple Y: k = |D(Y)|, l = |D+(Y)|, L = k + l, u = (k - l)/2, a = |Y ∩ V_1|, sigma = 1 if
T[Y] is transitive.

**(1a) Neighbourhood split.** For y in V_0 put u_y := f(y) - 13. Then
- y in V_0: |N+(y) ∩ V_1| = 13 + u_y, |N+(y) ∩ V_0| = 13 - u_y, |N-(y) ∩ V_1| = 13 - u_y, |N-(y) ∩ V_0| = 12 + u_y;
- y in V_1: |N+(y) ∩ V_1| = f(y), |N+(y) ∩ V_0| = 25 - f(y), |N-(y) ∩ V_1| = 25 - f(y), |N-(y) ∩ V_0| = 1 + f(y).
(Each line: d+ and d- split over the two classes; e.g. y in V_1 is beaten by 25 - f(y) of the other 25 vertices of V_1, so by
26 - (25 - f(y)) = 1 + f(y) vertices of V_0.) Arc counts: inside V_1 there are C(26,2) = 325 = sum_{V_1} f arcs, from V_1 to
V_0 there are sum_{V_1} (25 - f) = 650 - 325 = 325, so from V_0 to V_1 there are 676 - 325 = 351 = sum_{V_0} f. Hence
**sum_{V_0} u_y = 351 - 338 = 13** (valid without Case A; in Case A u_y >= 0 by the tail identity).

**(1b) Vertex-star identity.** For every vertex y of any tournament,
  sum_{Y ∋ y} k(Y) = sum_{w -> y} C(d+(w) - 1, 2),   sum_{Y ∋ y} l(Y) = sum_{y -> w} C(d-(w) - 1, 2),
because w dominates Y = {y, z, z'} iff w -> y and {z, z'} ⊆ N+(w) \ {y}, and symmetrically. In Setting B,
d+(w) - 1 = 25 - e(w) and d-(w) - 1 = 24 + e(w), so the summands are 300 (w in V_0) or 276 (w in V_1), resp. 276 or 300.
- y in V_1: sum k = (1 + f)300 + (25 - f)276 = 7200 + 24f; sum l = (25 - f)276 + 300f = 6900 + 24f.
- y in V_0: sum k = (12 + u)300 + (13 - u)276 = 7188 + 24u; sum l = (13 - u)276 + (13 + u)300 = 7488 + 24u.
**Hence sum_{Y ∋ y} (k - l) = 600 e(y) - 300 for every vertex y.** (For a general degree sequence the same computation gives
-287 + 599.5 e(y) - E-(y) + (Q-(y) - Q+(y))/2, with E-, Q± the sums of e, e^2 over N-(y), N±(y).)

**(1c) Class sums.** Summing (1b) over y in V_1 counts each triple a(Y) times:
  **sum_Y a(Y) u(Y) = 26*300/2 = 3900,  sum_Y u = 0,  sum_Y (3 - a) u = -3900.**

**(1d) Transitive/cyclic split: sum over transitive Y of u = 0 (so also over cyclic Y).** A transitive triple inside N+(w)
is counted once by its source t, so sum_{trans} k = sum_{arcs w->t} C(m_wt, 2) with m = common out-neighbours; dually
sum_{trans} l = sum_{arcs r->w} C(D_rw, 2). So sum_trans (k - l) = sum_P [C(m_P,2) - C(D_P,2)]. Now m_P - D_P = 51 - d-(p) - d-(p')
= 1 (GG), 0 (mixed), -1 (HH), and C(D+1,2) - C(D,2) = D, C(D-1,2) - C(D,2) = -(D - 1). So
  sum_trans (k - l) = sum_GG D_P - sum_HH D_P + 325.
Count sum_GG D_P = sum_w C(|N+(w) ∩ V_0|, 2) and sum_HH D_P = sum_w C(f(w), 2). Termwise
C(26 - f, 2) - C(f, 2) = 325 - 25f (w in V_0) and C(25 - f, 2) - C(f, 2) = 300 - 24f (w in V_1), so
sum_GG D - sum_HH D = (26*325 - 25*351) + (26*300 - 24*325) = (8450 - 8775) + (7800 - 7800) = -325. Hence sum_trans (k - l) = 0. ∎
(In a DRT(51) the same two class sums vanish; here they survive the loss of double regularity.)

**(1e) The L-moment.** sum_Y [C(k,2) - C(l,2)] = sum_Y u(L - 1) and the left side is sum_P [C(m_P,3) - C(D_P,3)], so

In Case A (D = 12 on GG, D = 12 + x on HH, sum_HH x = 325) this is 325*66 - sum_HH C(11 + x, 2) = -eta_T, the r4_MASTER value.
Combined with (1c), (1d) and L = 13 - a - sigma + X: **sum_Y X_Y u_Y = 3900 - eta_T in Case A.**

## §2. No vertex-deleted subtournament of an F1-tournament on 52 vertices is a DRT(51) (PROVED)

**Theorem 2.** Let T be a tournament on 52 vertices in which every triple has at least 5 dominators. Then for every vertex
x, T - x is not a doubly regular tournament on 51 vertices.

[S1102] S11 proved this for d+(x) in {24, 25, 26} and recorded d+(x) = 27 and d+(x) <= 23 as open. Both are closed here.

*Set-up (as in [S1102] S10-S11).* Suppose T' := T - x is a DRT(51). Put S = N+(x), s = |S| = d+(x), W = N-(x). A triple of
T' gains the dominator x exactly when it lies in S, so every triple of T' not inside S has >= 5 dominators in T' and every
triple inside S has >= 4. This is the hypothesis of the confinement Lemma C ([S1102] S10):
  K_S <= 4 C(s,3) + 3 T_S + (21/4) C_S - 5418.75,  K_S := sum_{Y ⊆ S} k_{T'}(Y),
with T_S, C_S the numbers of transitive and cyclic triples inside S. I re-derived Lemma C line by line: the certificate sum is
sum phi = -3825 - 5525 + 16575 = 7225 (sum u^2 = 678300 + 30.25*15300 + 36*5525 - 11*84150 - 12*33150 = 16575), the factored
forms phi_T(u) = -(2/3)(u + 1/2)(u - 1/2)(u - 3/2) and phi_C(u) = -(2/3)(u + 1)(u - 1)(u - 3/2) show phi <= 0 for every k >= 5
and phi = 4 (transitive) or 7 (cyclic) at k = 4, and k - 4 <= (3/4) cost(k) holds with equality only at transitive k = 7.

**Step 1: s <= 24 (generic; no structure of T used beyond Lemma C).** Since T_S + C_S = C(s,3) and 21/4 > 3,
  K_S <= 7 C(s,3) + (9/4) C_S - 5418.75 <= 7 C(s,3) + (9/4) c(s) - 5418.75 =: U(s),
where c(s) is the largest number of cyclic triples in an s-vertex tournament ((s^3 - s)/24 for odd s, s(s^2 - 4)/24 for even s).

## §4. The in-neighbourhood of an in-degree-25 vertex: (R25) is false; (P25) is the live question

**Lemma 4.1 (PROVED, F1 only).** Let T be a tournament on 52 vertices in which every triple has >= 5 dominators, and let
d-(v) = 25. Then either v is the head of a tight pair (some a -> v has |D({a, v})| = 11), or H := T[N-(v)] is a 12-regular
tournament on 25 vertices in which every pair has >= 5 common in-neighbours inside H.
*Proof.* For a in N-(v) the in-degree of a inside H is |N-(a) ∩ N-(v)| = |D({a, v})| >= 11 (F2). These 25 in-degrees add up
to C(25,2) = 300 = 25*12. If none is 11, all are 12. For a, a' in N-(v) the common in-neighbours inside H are exactly
D({v, a, a'}), which has >= 5 elements by F1. ∎
(With full S_4, H also has S_3, because a dominator of {v} ∪ W for a triple W ⊆ N-(v) beats v; this is (P25) of [S1102] S4.)

So if no 12-regular tournament on 25 vertices had all codegrees >= 5 — call that statement **(R25)** — every in-degree-25
vertex would head a tight pair and the whole no-tight branch (Case A, balanced or not, >= 26 such vertices) would die
using F1 alone. **(R25) is false.** [experiment] A regularity-preserving annealing (moves reverse a directed 3-cycle) found
two such tournaments; both were re-verified independently (valid tournament, every out-degree 12, every codegree >= 5):
- `research/compute/r25/codeg5_reg25_example_seed12.txt`: codegree histogram {5: 168, 6: 115, 7: 16, 8: 1}; 11 undominated triples;
- `research/compute/r25/codeg5_reg25_example_seed13.txt`: {5: 166, 6: 118, 7: 16}; 6 undominated triples.
Calibration that makes the earlier failures meaningful in hindsight: the same search solves the analogous "nearly doubly
regular" problems n = 17 (codegree >= 3) and n = 21 (codegree >= 4) in 3 of 3 runs each (about 6*10^6 and 1.3*10^7 moves);
at n = 25 it needed 1.2-1.6*10^8 moves (2 of 4 long runs), and all 30M-move runs had stopped at deficit 1-2. A SAT encoding
(`research/compute/r25/r25_sat.py`, `r25_sat2.py`) reproduces the small cases; the plain encoding did not finish at n = 25
in 15 minutes. **Also refuted:** all 16 cyclotomic Cayley candidates on GF(25) that [S1102] S4 proposed for (P25) have
codegree 4 somewhere and an undominated triple, and every Cayley tournament on Z_25 or Z_5 x Z_5 (2^12 connection sets each)
has minimum codegree <= 4. Since every vertex-transitive digraph of order p^2 is a Cayley digraph (Marušič 1985, "Vertex
transitive graphs and digraphs of order p^k"; cited, not re-proved here), **no vertex-transitive tournament satisfies even
the codegree half of (P25)**; the examples above are irregular objects.

**Hand structure theorem for the Cayley case on Z_5 x Z_5 (PROVED; the exclusion itself is the enumeration above).**
Let S ⊂ G = F_5^2 with S ⊔ (-S) = G \ {0} (a Cayley tournament, |S| = 12), N_S(d) = |S ∩ (S - d)| the codegree of 0 and d,
and suppose N_S(d) = 5 + z_d with z_d >= 0 for all d != 0 (so z_d = z_{-d}, sum z = 132 - 120 = 12). For a nontrivial
character chi (values in Z[zeta], zeta = e^{2 pi i/5}): |S^(chi)|^2 = 12 + sum_{d != 0} N_S(d) chi(d) = 7 + Z^(chi) with
Z^(chi) = sum_d z_d chi(d), and S^(chi) + conj S^(chi) = sum_{g != 0} chi(g) = -1, so Re S^(chi) = -1/2 and
**(2 S^(chi) + 1)^2 = -(27 + 4 Z^(chi)).** Write m_j = |S ∩ chi^{-1}(zeta^j)|; then m_0 = 2, m_j + m_{-j} = 5, and using
1 + zeta + ... + zeta^4 = 0, 2 S^(chi) + 1 = a(zeta - zeta^4) + b(zeta^2 - zeta^3) with **a = 2 m_1 - 5, b = 2 m_2 - 5 odd**.
With c_j = sum of z_d over chi(d) = zeta^j (c_1 = c_4, c_2 = c_3, c_0 = 12 - 2(c_1 + c_2)) and zeta + zeta^4 = (sqrt5 - 1)/2,
zeta^2 + zeta^3 = -(sqrt5 + 1)/2, (zeta - zeta^4)^2 = (-5 - sqrt5)/2, (zeta^2 - zeta^3)^2 = (sqrt5 - 5)/2,
(zeta - zeta^4)(zeta^2 - zeta^3) = -sqrt5, comparing rational and sqrt5 parts gives
  a^2 + b^2 = 30 - 4(c_1 + c_2),   a^2 + 4ab - b^2 = 4(c_1 - c_2).
Odd squares are 1 mod 8, so c_1 + c_2 is odd; c_1 + c_2 = 3 would need a = ±3, b = ±3 and then 4ab = ±36 = 4(c_1 - c_2) with
|c_1 - c_2| <= 3, impossible. So c_1 + c_2 ∈ {1, 5} and c_0 ∈ {10, 2}. Now c_0(chi) is the z-mass on the line ker chi, the six
lines through 0 partition G \ {0}, and their masses add up to 12; a line of mass 10 would leave 2 for five lines that each need
>= 2. Hence **every line through 0 carries z-mass exactly 2, all z_d ∈ {0, 1}, every codegree is 5 or 6, and the codegree-6 set
is one ± pair from each line.** Writing t_v ∈ {1, 2} for the chosen multiple on the line through v and s_v = (t_v/5), the count
of codegree-6 elements on each pair of opposite parallel lines must avoid {1, 4}; this says Cs has entries in {±1, ±5}, where
C is the Paley conference matrix of order 6 (C_{Kv} = (det(w_K, w_v)/5)). Since |Cs|^2 = 5|s|^2 = 30, Cs has one entry ±5 and
five entries ±1, i.e. s = sigma C e_K + s_K e_K: 24 of the 64 sign vectors survive. The remaining (a, b) conditions are what
the exhaustive enumeration rules out; a hand finish of this last step is not attempted here.

**Spectral form of the codegree condition (PROVED).** Let H be regular on 25 vertices, M its skew (+-1) matrix, A its 0/1
adjacency, D_ab the codegree (in a regular tournament common in- and out-neighbourhoods have the same size, so
mid(a -> b) = 11 - D and cyc(a -> b) = 12 - D). Then (MM^T)_ab = 4 D_ab - 23 for a != b, and with D = 5 + y,
  MM^T = 27 I + 4Y - 3J,  equivalently  A^2 + A = 7(J - I) - Y,
so "all codegrees >= 5" is "(A^2 + A)_ab <= 7 for a != b": at most 7 paths of length <= 2 from any vertex to any other
(the mean is 156/24 = 6.5). A is normal (M commutes with J), its eigenvalues on 1^⊥ are (-1 + i mu)/2, and MM^T has
eigenvalues 27 + 4 theta (theta in spec Y on 1^⊥), each with even multiplicity. The Pfaffian bookkeeping gives
prod_j s_j^2 = 25 pi^2 with pi = |Pf(H - a)| odd and independent of a (adj M = p p^T with p in ker M = span 1), i.e.
det(27 I + 4Y) = 3 * 5^6 * pi^4. I checked this against 2-adic obstructions: it holds mod 32 whatever Y is (both sides are
27 or 11 mod 32 according to the parity of sum y^2), so there is no Bruck-Ryser-Chowla-type obstruction at the 2-adic level;
consistent with the examples found.

**Per-vertex identities in such an H (PROVED).** Fix a, R = N-(a), O = N+(a) (12 each), alpha_r = D_ar - 5, beta_o = D_ao - 5
(each family sums to 6). T[R] has in-degrees 5 + alpha, T[O] has out-degrees 5 + beta, r in R beats 5 + alpha_r vertices of O,
o in O is beaten by 5 + beta_o vertices of R. The codegree excess (sum of D - 5) splits as: pairs inside R: 30 + Q_a/2; pairs
inside O: 30 + Q_a/2; the 144 mixed pairs: 78 - Q_a; pairs through a: 12; total 150. Here Q_a = sum_b (D_ab - 5)^2, so
**Q_a <= 78 at every vertex**; and for each o in O, beta_o + sum_{w in Q_o} alpha_w + sum_{w in N-_O(o)} beta_w <= 12.

**What is left of this route.** Lemma 4.1 with full S_4 says: an in-degree-25 vertex without a tight in-pair carries a (P25)

## §7. Deciding (P25) (continued 5 Nov): exhaustive case split, solver limits, and a parity tool

**Exhaustive case split (PROVED).** Let D_max = 5 + m be the largest codegree of a (P25) tournament, vertex 0 an endpoint of
a pair attaining it, O = N+(0) = {1..12}, R = N-(0) = {13..24}. Then D(0, r) = 5 + alpha_r (in-degree inside T[R]) and
D(0, o) = 5 + beta_o (out-degree inside T[O]); alpha and beta are partitions of 6, max(alpha ∪ beta) = m, and every codegree
is <= 5 + m. Sorting R, O by these values and ordering each equal block along a Hamiltonian path of the block (Rédei) is a
relabelling. So the 121 cubes (alpha, beta) cover every case; their m-distribution is 1/15/33/32/19/21 for m = 1..6.

**Lemma 7.1 (Gram identity; PROVED).** For every regular tournament on 25 vertices with skew matrix M, let Y be the
codegree-excess matrix (Y_ab = codeg(a, b) - 5 for a != b, Y_aa = 0). Then **MM^T = 27 I + 4Y - 3J** (diagonal: 24 = 27 + 0 - 3;
off-diagonal: (MM^T)_ab = 4 codeg - 23 = 4(5 + y_ab) - 23 = 4 y_ab - 3, §4), so Y = (3J - 27I - M^2)/4 is a polynomial in M and J, hence
**MY = YM**. M is real skew, so every nonzero eigenvalue of MM^T = -M^2 has even multiplicity; as MM^T 1 = 0 and M acts on each
eigenspace of Y in 1^⊥ with M^2 = -(27 + 4 theta), **every eigenvalue theta of Y on 1^⊥ has even multiplicity** (theta = -27/4 is
excluded since theta is an algebraic integer). [check] On both examples of §4: MM^T = 27I + 4Y - 3J, MY = YM, and the 24
eigenvalues of Y on 1^⊥ occur in exactly 12 equal pairs.

**Theorem 7.2 (PROVED; F1 + regularity only).** In every 12-regular tournament on 25 vertices with all codegrees >= 5, the
codegree-5 graph G_5 contains a triangle.
*Proof.* Each vertex has codegree excess sum 12 over its 24 partners (§4), so at most 12 partners have codegree >= 6 and
G_5 has minimum degree >= 12 > 2*25/5. A triangle-free graph with minimum degree > 2n/5 is bipartite (Andrásfai-Erdős-Sós);
both parts have >= 12 vertices, so they have 12 and 13, and every vertex of the 13-part has degree exactly 12: G_5 = K_{12,13}.
Then the codegrees are forced: in the 13-part B every vertex has 12 non-neighbours in G_5 sharing excess 12, so codeg = 6
inside B; in the 12-part A every vertex has 11 non-neighbours sharing excess 12, so codeg = 6 inside A except one 7 per
vertex, a perfect matching P. Hence MM^T = 24I + (-3 on A x B, 1 inside B, 1 inside A, 5 on P). Its spectrum: on 1_B^⊥
(supported on B) 23 with multiplicity 12; on 1_A^⊥ the matrix 23I + 4P gives 27 (pair-symmetric vectors, multiplicity 5) and
19 (pair-antisymmetric, multiplicity 6); on span{1_A, 1_B} the matrix [[39, -39], [-36, 36]] gives 0 and 75. The eigenvalues
75 (multiplicity 1) and 27 (multiplicity 5) have odd multiplicity, contradicting Lemma 7.1. ∎ [check] numerically:
spectrum {0: 1, 19: 6, 23: 12, 27: 5, 75: 1}.
So S_3 can never be rescued by avoiding "cells": every (P25) candidate has cells, the exact place where S_3 failed in every
example. Note that CaDiCaL and Kissat had not refuted this exact-pattern branch after several minutes, although the parity
argument is three lines: a direct illustration of the solver wall.

**The parity test as a tool.** Any branch that forces the codegree pattern Y is decided instantly by computing the spectrum
of 27I + 4Y - 3J. The m = 1 cube (all codegrees 5 or 6) is the next candidate: there Y is the adjacency matrix of a
12-regular graph whose spectrum on 1^⊥ must be paired (the 15 strongly regular graphs srg(25,12,5,6), eigenvalues 2 and -3
with multiplicity 12 each, pass; generic graphs fail), and M commutes with it.

**The m = 1 cube (all codegrees 5 or 6; PROVED facts).** Let A be the adjacency matrix of the codegree-6 graph Γ (12-regular).
Then MA = AM, and also TA = AT for the 0/1 adjacency T = (M + J - I)/2, i.e. for all a, c:
|N+(a) ∩ Γ(c)| = |Γ(a) ∩ N-(c)| (every vertex has 6 Γ-neighbours among its in- and 6 among its out-neighbours). MA is skew,
so tr(M^2 A^2) = -||MA||_F^2, and M^2 = -(27I + 4A - 3J) gives tr(M^2 A^2) = 2700 - 24t with t the number of triangles of Γ.
For a ~ c in Γ, (MA)_ac is a sum of 11 terms ±1, so odd; hence ||MA||^2 >= 300 and **Γ has at least 125 triangles**.
(Consistent, not a contradiction; srg(25,12,5,6) has 250.)

**The m = 6 cubes (structure, PROVED).** If D(0, q) = 11 with q in R (alpha = (6)), then q is a sink of T[R], mid(q -> 0) = 0
and cyc(q -> 0) = 1: 0 and q are near-twins (both beaten by R \ {q}; both beat O \ {w} for the one w with 0 -> w -> q).
codeg(q, o) = 4 + beta_o + [w -> o] for o in O \ {w}, so w beats every o with beta_o = 0; codeg(q, r) = 5 + [w -> r]; and
T[R \ {q}] is 5-regular on 11 vertices with S_2 (S_3 on {0, r, r'}). There are exactly 1,223 regular tournaments on 11

## §8. The 551-class decomposition of the alpha = (6) cubes (5 Nov) -- built, validated, does not break the solver wall

**Generator ([experiment], validated).** `research/compute/p25/gen_regular.py` enumerates regular tournaments on 2t + 1
vertices up to isomorphism (vertex 0 fixed; T[N+(0)], T[N-(0)] range over class representatives of t-vertex tournaments;
the arcs between them over all 0/1 matrices with the forced margins; canonical form = lex-least adjacency string over a
colour-refinement/individualisation search tree). It reproduces the known counts exactly: 3 (n = 7, one with S_2: QR_7),
15 (n = 9), and **1,223 regular tournaments on 11 vertices, 551 of them with S_2** (31,405 candidates, 22 s) -- an
independent confirmation of the archive's 551. List: `research/compute/p25/reg11_S2_canon.txt`.

**Decomposition (PROVED sound).** In an alpha = (6) cube, q = 13 is beaten by all of R \ {q}, so every triple {0, r, r'} must
be dominated inside R \ {q}: T[R \ {q}] is 5-regular with S_2. With the R-side symmetry breaking removed, every remaining
constraint is invariant under permuting 14..24, so any solution can be relabelled to make T[R \ {q}] equal its class
representative. Hence "all 551 class instances UNSAT" implies "cube UNSAT". Scripts: `p25_dec551.py` (incremental CaDiCaL
under the 66 assumptions fixing T[R]), `p25_dec551_units.py` (fresh solver, unit clauses), optional lex-leader breaking of
the O-side: rows of arcs from R, lexicographically non-increasing inside each beta-block (valid since R is now rigidly
labelled; the encoding was checked exhaustively against lex >= on all pairs of 4-bit vectors).

**Two bugs caught before any result was used.** (1) The class strings were decoded character-wise, so every class came out
transitive and every instance was "UNSAT" in 0.0 s; an UNSAT core (six arcs out of vertex 14) exposed it. (2) The first
version of the lex encoding forced the first "equal-so-far" bit false; a brute-force check against all 64 pairs of 3-bit
vectors exposed it. Both fixed and re-verified (all 551 decode as 5-regular S_2; lex encoding agrees on all 256 pairs).

**Outcome ([experiment]).** For the open cube beta = (1^6): classes 0-2 without lex breaking (Kissat, 180 s each), classes
0-3 with lex breaking (Kissat, 240 s each), class 0 incremental CaDiCaL (15 min): **no verdict in any of them**; without S_3,
classes 0-2 were also undecided after 300,000 conflicts. Fixing T[N-(0)] does not activate strong local constraints: the
sets Q'_o = N-(o) ∩ (R \ {q}) must be total in-dominating sets of T[R \ {q}] (S_3 on {0, r, o}), but about 180 of the 330
four-subsets and about 396 of the 462 five-subsets qualify in every class (min/median/max 165/180/204 and 396/396/403). So
there is no cheap further enumeration layer, and the ~3,300 (class, beta) instances, each well beyond 15 minutes, are out of
reach on this machine. **The decomposition is sound and validated but does not get past the solver wall.**

**What this says about method.** The only branch closed decisively today (Theorem 7.2, G_5 triangle-free) fell to the Gram
identity, in three lines, while CDCL could not refute it in minutes. Plain SAT, with or without structured decomposition,
does not see the quadratic/spectral obstructions that govern (P25). A realistic path to deciding (P25) has to put that
algebra into the search: e.g. enumerate codegree patterns Y branch by branch and prune with the paired-spectrum condition of
Lemma 7.1 before any SAT call, or find further hand lemmas of the Theorem 7.2 type that force Y in sub-branches.
