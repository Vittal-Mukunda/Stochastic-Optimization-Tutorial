## 3. Lemma C': confinement in every regular tournament on 51 vertices (T3, PROVED)

Define, for every integer L,
  **lambda(L) := Phi_L(5 - L/2) = s^3/3 - 3s^2/4 + 2s/3,  pi(L) := Phi_L(4 - L/2) = lambda(L) + s^2 + 3,  s = L - 10,**
the values at k = 5 and k = 4. Values for L = 8..16: lambda = -7, -7/4, 0, 1/4, 1, 17/4, 12, 105/4, 49; pi = 0, 9/4, 3,
17/4, 8, 65/4, 31, 217/4, 88.

**Fact 1.** For all integers L and k >= 5, Phi_L(k - L/2) <= lambda(L).
*Proof.* Put u0 = 5 - L/2 = -s/2 and k = 5 + j. Direct expansion:
Phi_L(u0 + j) - Phi_L(u0) = j * [-s^2 + (j+1)s - (2/3)j^2 + j - 4/3]. For j = 1 the bracket is -(s-1)^2. For j = 2 it is
-(s-1)(s-2), which is <= 0 at every integer s. For j >= 3 its maximum over real s is -(5/12)j^2 + (3/2)j - 13/12. That equals
-1/3 at j = 3 and decreases for j >= 2. ∎ (Equality: L = 11 at k = 6, 7; L = 12 at k = 7.)

**Fact 2.** For all integers L and k >= 5, Phi_L(k - L/2) + (4/3)(k - 4) <= pi(L).
*Proof.* Put u1 = 4 - L/2 and k = 4 + m. Then
Phi_L(u1 + m) - Phi_L(u1) + (4/3)m = m * [-s^2 + (m-1)s + 3m - (2/3)m^2 - 4]. The bracket is -s^2 - 5/3 for m = 1,
-s^2 + s - 2/3 < 0 for m = 2, and -(s-1)^2 for m = 3. For m >= 4 its maximum over real s is -(5/12)m^2 + (5/2)m - 15/4,
which is -5/12 at m = 4 and decreases after. ∎ (Equality only at L = 11, k = 7; this is the ratio 3/4 of Lemma C.)

where sum u^2 = 16575 - Gamma2/4 + Gamma3/3 by (2.5) and K_S = sum_{Y in S} k.
*Proof.* For Y not inside S, k >= 5, so Phi_{L}(u) <= lambda(L) by Fact 1. For Y inside S, Phi_L(u) + (4/3)(k-4) <= pi(L):

## 5. Lemma R: the pairs with g = -1 are rigid (T5, PROVED)

**Lemma R.** Let P be a pair of B with g_P = -1. Then omega_P = lambda_B(P) = 5. Every one of the 25 triples {w} + P
(w in W) has exactly 5 dominators. n_cyc(P) = 7. The triple {b0} + P has k = l = 5.
*Proof.* The triples {w} + P are not through b0 and not inside B, so each has >= 5 dominators by (ii). Their dominators
are the vertices of D(P) \ {b0} that beat w (b0 beats no vertex of W). A vertex of W cap D(P) beats 12 vertices of W, and
a vertex of B cap D(P) beats 13. So sum_{w in W} k({w} + P) = 12 omega_P + 13 lambda_B(P) >= 125. With
omega_P + lambda_B(P) = 11 + g_P = 10 this reads 120 + lambda_B(P) >= 125, so lambda_B(P) >= 5. Also omega_P >= 5 by (i), so
lambda_B(P) <= 5. Hence both are 5, the sum is exactly 125, and each of the 25 triples has exactly 5. Then
n_cyc = 1 - g + lambda_B = 7. For {b0} + P, k = omega_P = 5 and l = |B cap N+(b) cap N+(b')| = lambda_B(P) = 5 (in the
12-regular T'[B], common out- and in-neighbourhoods have the same size). ∎
For g >= 0 the same count gives only lambda_B >= -7 - 12g, which is vacuous.

## 6. Corollary S: sparse perturbations are impossible (T6, PROVED)

For b in B let d_b be the number of pairs of B at b with g != 0.

**Corollary S.** In every RTF member, d_b >= 3 for some b in B.
*Proof.* Suppose d_b <= 2 for all b. (1) If g_P >= 2 at b, the in-sum or out-sum at b that contains P needs at least two
-1's, so d_b >= 3. Hence g takes values in {-1, 0, 1}. (2) If d_b = 2, the two nonzero pairs at b are both in-arcs or both
out-arcs of b, with opposite signs: one of each kind would leave an in-sum of +-1. (3) A triangle of B with three nonzero
pairs would make each of its vertices a source or a sink of the triangle, by (2). No triangle has that property, so
Theta = 0. A cyclic triangle with two nonzero pairs would give their common vertex one nonzero in-arc and one nonzero
out-arc, so Psi_C = 0. (4) With n pairs of each sign, Gamma2 = 2n, Gamma3 = 0, and 2n = (1/2) sum_b d_b <= 25, so n <= 12.
(5) Lambda = sum_{g=1} lambda_B - sum_{g=-1} lambda_B >= 0 - 5n by Lemma R. Then the left side of §4 is
44.5*2n - 2 Lambda <= 99n <= 1188 < 4625/3, so the RTF does not survive. ∎
(The case n = 0 is the DRT case, dead by [S] S11.) In particular g is never supported on vertex-disjoint alternating 4-cycles,
paths or cycles.
